# Liangting Wang — Research Portfolio

Static GitHub Pages portfolio for 2027 PhD applications.

## Publish on GitHub Pages
1. Create a public GitHub repository, e.g. `liangting-research-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, `favicon.svg`, and the optimized JPG files in `assets/` to the repository root.
3. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.

All published assets use local relative paths, so the portfolio does not depend on expiring third-party image links.
